# Romantic Interactive Invite

Это одностраничный адаптивный интерактивный сайт-приглашение.

Как запустить локально:

1. Клонируйте репозиторий

   git clone https://github.com/howpentagon-sketch/Me-.git
2. Перейдите в папку проекта

   cd Me-
3. Установите зависимости и запустите

   npm install
   npm start

Откроется локальный dev-сервер (Vite). Страница полностью статическая — база данных не нужна.

Описание реализации:
- Чистая HTML/CSS/JS структура в src/
- CSS содержит адаптивные стили, градиенты, эффекты «зефирных облаков», сердца и свечения
- JS управляет сценами, печатающимся текстом, интерактивным конвертом и финальной анимацией

Если хотите — могу добавить в проект возможность заменить текст на персонализированный (из простого JSON) или добавить ваш фото в отдельной ветке.
